# LangChain Deep Technical Blog Project

## 📌 Overview
This project demonstrates the implementation of core LangChain components using Python.

The notebook covers:
- LLMs (Language Models)
- Prompt Templates
- Chains (LCEL)
- Memory
- Tools (Agent Concept)
- Document Loaders
- Vector Stores (FAISS)

---

## 🛠 Tech Stack
- Python
- LangChain
- OpenAI API
- FAISS (Vector Database)

---

## 🚀 How to Run

1. Clone the repository:
   git clone <your-repo-link>

2. Install dependencies:
   pip install -r requirements.txt

3. Open Jupyter Notebook:
   langchain_project.ipynb

4. Run cells step by step
