# AI Resume Screening System

## 🚀 Overview
This project is an AI-powered Resume Screening System built using LangChain.

It takes a resume and a job description as input and evaluates how well the candidate fits the role.

---

## 🎯 Features
- Extracts skills, tools, and experience from resumes
- Matches candidate profile with job description
- Assigns a score (0–100)
- Provides explanation for the score

---

## 🧠 Pipeline Flow
Resume → Extract → Match → Score → Explain

---

## 🛠️ Tech Stack
- Python
- LangChain
- HuggingFace (GPT2)
- Transformers
- PyTorch
