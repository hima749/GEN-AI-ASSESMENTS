# GEN-AI-ASSESMENTS
# GenAI Prompt Engineering Assignment – LangChain

## 📌 Overview
This project focuses on building a **dynamic and reusable prompt system** using LangChain PromptTemplate instead of hardcoded prompts.

The assignment demonstrates how to design structured prompt pipelines that can adapt based on user inputs.

---

## 🎯 Objectives
- Replace hardcoded prompts with reusable templates
- Build multi-input prompt systems
- Create prompt variations for different use cases
- Implement ChatPromptTemplate with role-based behavior
- Add input validation for better control
- Develop a mini prompt generator application


 Tech Stack
- Python
- LangChain
- Jupyter Notebook / Google Colab

 Tasks Implemented

 Task 1: Basic PromptTemplate
Converted static prompt into a reusable template.

 Task 2: Multi-Input Prompt System
Handled multiple inputs like topic, audience, and tone.

 Task 3: Prompt Variations Engine
Created templates for:
- Teaching
- Interview
- Storytelling

 Task 4: ChatPromptTemplate System
Built a role-based system:
- Teacher
- Interviewer
- Motivator

 Task 5: Input Validation Layer
Validated inputs and handled incorrect values using default settings.

 Task 6: Prompt Generator Function
Developed a function to dynamically generate prompts based on:
- Topic
- Audience
- Tone
- Style

Task 7: Template Reusability Test
Tested one template with multiple inputs to ensure reusability.

 Workflow Pipeline
User Input → Validation → Prompt Template → Generated Prompt → Output

 Key Learnings
- Learned how to design reusable prompt systems
- Understood modular prompt engineering
- Explored real-world use of LangChain PromptTemplate
- Improved structured thinking for LLM interactions

 Output
The notebook includes:
- Clean and structured code
- Comments explaining logic
- Outputs for each task

 Conclusion
This assignment helped shift my understanding from writing simple prompts to designing scalable prompt systems, which is essential in real-world Generative AI applications.
